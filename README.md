# แบบสอบถามข้อมูลเว็บไซต์

เว็บฟอร์มภาษาไทยสำหรับรวบรวมข้อมูลธุรกิจและส่งคำตอบไปยังอีเมลผู้ดูแลโดยตรง

## เริ่มใช้งาน

1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน `npm install`
3. คัดลอก `.env.example` เป็น `.env`
4. ตั้งค่า `SMTP_HOST`, `SMTP_PORT`, `SMTP_SECURE`, `SMTP_USER` และ `SMTP_PASS` ให้ตรงกับบริการอีเมลผู้ส่ง
5. ตรวจสอบ `RECIPIENT_EMAIL` ว่าเป็นอีเมลที่ต้องการรับคำตอบ
6. รัน `npm start` แล้วเปิด `http://localhost:3000`

ค่าตั้งต้นตัวอย่างใน `.env.example` ใช้ Gmail SMTP โดย `SMTP_USER` คือบัญชี Gmail สำหรับส่งอีเมล และ `SMTP_PASS` ควรเป็น App Password ของบัญชีนั้น ไม่ใช่รหัสผ่านปกติ

ห้ามเผยแพร่ไฟล์ `.env` หรือ App Password ในซอร์สโค้ด และเมื่อนำขึ้นออนไลน์ควรใช้ HTTPS รวมถึงกำหนดค่าตัวแปรแวดล้อมในบริการโฮสต์แทนการอัปโหลด `.env`
